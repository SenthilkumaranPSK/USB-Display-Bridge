# USB Display Bridge

A wired, USB-only bidirectional display bridge between an Android phone and a
desktop PC.

**Status:** scaffold + adb handshake (M0). No video yet.

See [CLAUDE.md](./CLAUDE.md) for the architecture, constraints, and milestones.
